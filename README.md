# Code 16 Guidelines

Code 16 coding guidelines as AI skills, for [Laravel Boost](https://laravel.com/docs/boost) and more.

## Installation

```bash
composer require laravel/boost --dev
composer require code16/guidelines-skills --dev
php artisan boost:install
```

## Update

```bash
composer update code16/guidelines-skills
php artisan boost:update
```

## Included

| Skill | Description |
|-------|-------------|
| `code16-laravel-php` | Laravel & PHP conventions, PSR standards, control flow, naming |
